# Noctra Client — Design Assets

UI/UX design mockups and visual reference assets for **Noctra Client** (Minecraft Desktop Launcher).

## Contents

The [`design/`](./design/) directory contains the high-resolution UI/UX design mockups covering all client interfaces:
- Login Screen & Auth
- Navigation Rail & Layout
- Home Overview & Game Launch
- Social Flyout & Noctra Relay
- Locker (Wardrobe, 3D Skin Viewer, Capes)
- Versions & Profiles Management
- Modrinth Content Browser
- Settings & Customization
- Offline Fallback & System States
