# Noctra Client — Design System & UI/UX Assets

Comprehensive design system, UI/UX specification, and visual reference assets for **Noctra Client** (Minecraft Desktop Launcher).

---

## Repository Contents

- **[Design Specification](design/DESIGN_SPECIFICATION.md)**: Full architecture breakdown across Login, Navigation Rail, Social Flyout & Relay, Wardrobe / Locker, Instance Management, Modrinth Browser, Settings, and System States.
- **[Design Implementation Guide](design/DESIGN_IMPLEMENTATION.md)**: Foundation design tokens, typography, geometry constants, and implementation notes.
- **Visual Assets**:
  - `design/`: Design mockups and reference screenshots.
  - `redesign/`: Direct mirror for backwards-compatibility with internal references.

## Design System Summary

### Color Tokens

| Token | Hex | Usage |
| :--- | :--- | :--- |
| **Beyond Black** | `#060305` | Primary app background |
| **Surface Dark** | `#0c090c` | Navigation rail, drawer, card backgrounds |
| **Surface Elevated** | `#141015` | Modals, elevated cards, popups |
| **Purple Freedom** | `#a051a2` | Primary brand accent |
| **Purple Hover** | `#b665b8` | Interactive hover state |
| **Launch Teal** | `#3aa89f` | Primary Launch button gradient |
| **Launch Teal Hover** | `#48c1b7` | Launch button hover state |
| **Light Gray** | `#d2d2d2` | Body text, primary typography |
| **Muted Gray** | `#75717a` | Secondary text, hints |

### Typography

- Primary Display & Body: **Figtree**
- Monospace / System Data: **JetBrains Mono**
